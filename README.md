# Личный финансовый менеджер

## О проекте

Этот проект представляет собой приложение личного финансового менеджера, созданное в рамках онлайн-школы METHED. Приложение помогает пользователям управлять своими финансами, отслеживать доходы и расходы, а также генерировать отчеты о финансовом состоянии.

## Технологии

### Клиентская часть

Проект разработан с использованием современного JavaScript (ES6 и выше) и включает в себя следующие ключевые концепции:

- **Идентификаторы**: использование переменных и констант.
- **Типы данных**: работа со строками, числами, объектами и массивами.
- **Работа с DOM**: манипуляция элементами на странице.
- **События**: обработка кликов и ввода данных.
- **Условные операторы**: использование `if` для принятия решений.
- **Циклы**: итерация по массивам и объектам.
- **Функции**: применение стрелочных функций и функциональных выражений.
- **JS модули**: импорт и экспорт модулей.
- **Асинхронный код**: работа с Promises и `async/await`.
- **Делегирование событий**: оптимизация обработки событий.
- **Шаблонные строки**: интерполяция строк для удобства.
- **Деструктуризация**: использование операторов `rest` и `spread`.

### Взаимодействие с сервером

Приложение взаимодействует с сервером, используя следующие технологии:

- **RESTful API**: основы работы с RESTful архитектурой.
- **HTTP-запросы**: отправка запросов через Fetch API или Axios.
- **Обработка ответов**: работа с JSON и обработка ошибок.

### Генерация отчетов

Для формирования отчетов приложение использует:

- **Работа с массивами и объектами**: сбор статистических данных.
- **Методы работы со временем и датой**: управление временными данными.
- **Формирование отчетов**: создание отчетов с графиками для визуализации финансовых данных.
